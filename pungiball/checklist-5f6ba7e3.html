OAuth consent → In produzioneGoogle Cloud → schermata consenso → Pubblica (o login Google limitato ai tester)
Limiti API keyGoogle Cloud → credenziali → restringi la chiave ad Identity Toolkit + RTDB (sicurezza)
Regole RTDB definitiveusers/{uid}, system, supportMessages ok — su leaderboard aggiungi ".indexOn": ["p"] (ordina per punti, altrimenti scarica tutto)

Firebase

Progetto punchballarcade — RTDB europe-west1. Auth REST (no SDK).
Struttura: users/{uid} salvataggi · supportMessages/{uid} ticket · leaderboard/{week}/{uid} futura classifica · system/{id} messaggi.

Messaggi sistema — formato

{ titolo, testo, data, ora, tipo, ricompensa, avviso, giorni }
tipo: all / banner / msg · ricompensa: monete RITIRA · giorni: scadenza · avviso: etichetta warning.
File pronto: system_export.json → importare su nodo system.

PlayerPrefs chiave

PBMonete, PBName, PBLiv, PBExp, PBChar, PBOwned_*, PBCLv_*, PBUpg_*_*, PBRankPoints, PBRewardNext, PBTutorial, PBSysSeen_*, PBSysClaim_* + sessione PB_Fb*
